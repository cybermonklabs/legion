# The list of scripts/red-at-base.sh for the change in which the daemon decides a tester's move from
# the check states that Dispatch publishes, and a phase completion carries no verdict. Run it at the
# commit that the change merges into:
#
#   bash scripts/red-at-base.sh --base <that commit> --list scripts/e2e/check-states.red.txt
#
# Each line names one test or one case that this change adds. The tool runs it at that commit, with
# only the line's files copied in, and each line must read RED or BUILD-FAILED: a test that passes
# there cannot tell the change from the commit it merges into. The lines follow the before_merge
# checks of the change's Verification document, in its order, one line for each test or case that a
# check runs: the check that runs two tests has two lines, and the check that runs two cases has
# two. The comment above each line names its check and says why the line fails at that commit. A
# line's files are its test file and each new helper, fixture or script that the test reads, never
# a file of the code under test, which is the change itself.
#
# The environment gives DISPATCH_TEST_DATABASE_URL to the envoy lines and LEGION_TEST_PG_DSN to the
# daemon and e2e lines. The e2e lines also need what the header of scripts/e2e/check-states.sh
# names (LEGION_OMP_PATH among it), and the last line needs SKILL_SCENARIOS_LABEL_PATCHES and the
# rig's model route (the header of states-read-check.sh).
