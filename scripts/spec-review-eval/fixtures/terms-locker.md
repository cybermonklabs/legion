# Terms

- **agent**: A program that runs a model to do work on the code or the texts of the locker.
- **compartment**: One box of the locker with a door, which holds one parcel at a time.
- **courier**: A worker who brings parcels to the locker and puts each one in a compartment.
- **door controller**: The component of the locker that opens and closes each door.
- **kiosk**: The screen and the keypad of the locker, where a tenant types a pickup code.
- **locker**: The system of ACME that keeps parcels in compartments until a tenant takes them.
- **notice**: A message that the locker sends to a tenant or to a courier about one parcel.
- **parcel**: A package that a courier puts in a compartment for one tenant.
- **pickup code**: A number of 6 digits that opens the door of one compartment for one parcel.
- **slot**: A time window of one hour in which a courier can bring parcels to the locker.
- **tenant**: A resident of the building who gets parcels from the locker.
