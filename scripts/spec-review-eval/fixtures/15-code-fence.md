# Alarms of the doors

## Terms

```text
- **door alarm**: A sound that the door controller makes when a door of the locker stays open.
```

## Statements

:::requirement{#door-alarm-start}
The door controller sounds the door alarm when a door stays open for more than 2 minutes.
:::

:::requirement{#door-close-60}
The door controller closes an open door of a compartment after 60 seconds.
:::
