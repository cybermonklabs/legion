# Terms

- **agent**: A program that runs a model to do work for the person.
- **answer**: The reply of the person to an ask, which closes the ask.
- **approval request**: A request that asks the person to approve one version of a document.
- **ask**: A question in Dispatch that waits for the answer of the person.
- **digest**: One message that Dispatch sends the person each day, with each ask that waited more than 24 hours.
- **document**: A text with versions that an issue holds.
- **inbox**: The page of Dispatch that shows the person each ask and each approval request that waits for the person.
- **issue**: A record of Dispatch that holds one piece of work, with its status, its documents and its asks.
- **person**: The human who answers each ask and approves each change to The Spec.
- **session**: One conversation of an agent, with its id, in which the agent does its work.
- **summary**: The text of an approval request that says what the person approves.
