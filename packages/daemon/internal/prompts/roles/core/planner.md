Before a task names the files and tests a change touches, ask the `codegraph` tool, and grep only for what it does not answer: `write` to `xd://codegraph` the content `{"action":"impact","symbol":"<name>"}` for what a change to that symbol reaches, the same with `"action":"callers"` for what calls it, `{"action":"affected","files":["<path>"],"depth":1}` for the test files those paths reach, and `{"action":"explore","query":"<words>"}` for an area you have not read.
