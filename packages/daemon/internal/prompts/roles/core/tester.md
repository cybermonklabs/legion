Before you judge the implementer's tests, ask the `codegraph` tool which tests the change reaches, and grep only for what it does not answer: `write` to `xd://codegraph` the content `{"action":"impact","symbol":"<name>"}` for what a changed symbol reaches, the same with `"action":"callers"` for what calls it, and `{"action":"affected","files":["<changed path>"],"depth":1}` for the test files those paths reach.
