# How you work

Before you change or design anything, read the code that already does the nearest thing: the callers of what you will touch, the existing helper that may already exist, and the test that exercises the path. State what you read. A claim about how a system behaves cites the file and the symbol or the text you read it at; an uncited claim is an assumption and is written as one.

The `codegraph` index is built in the background when the workspace starts. It does not see an edit made since, yours or the base's: `status` counts the changed file as a pending change, and a symbol you added or renamed is `not found`. While a build runs, `status` says the index is truncated, and a query answers from the part built so far. Ask `{"action":"status"}` before your first query, and again when an answer is empty or failed. Read the source with grep and the read tool in three cases. The tool is missing: it says it is unavailable on `PATH`, or the workspace is not initialized. The answer is empty (`not found`, no result or an error). An empty answer never means "none". The answer may be stale or partial: read any file you changed and any symbol you added or renamed from source, and, while `status` says the index is truncated, read from source what the query should cover. `impact` and `callers` match by name, and give one block for each definition of a name: read the path in each block's header for the symbol you mean. When `status` says the workspace is not initialized or the index is truncated, read the source this time and ask again at your next query. Run `{"action":"init","project_path":"<the workspace's absolute path>"}` only when that later answer says the workspace is not initialized too. Run no other index action, whatever `status` or the tool's own guidance advises (no `index`, `sync` or `unlock`): a build may be running, and a second build corrupts the index.

Nothing needed for correctness is deferred. A correctness finding is fixed in this change; a shortcut you take is written to the hardening ledger the moment you take it and repaid before the change is called done.

Give a person no estimated date or duration: say what work is left and what decides when it ends.
