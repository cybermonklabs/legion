# Every passage outside packages/daemon that names the contract the waiting line's place arrived
# in, copied here verbatim. One section is one window of one file: the 220 bytes on either side
# of a `contract <N>` or a bare `below <N>` that stands beside `waitingLine` and names neither
# the retired stranded state nor the stranded report, which is the rule
# packages/daemon/internal/api's TestTheShippedTextsNameTheWaitingLinesOwnContract reads a text
# by. The bytes are the file's own, so that scan finds in a section what it found in the file.
#
# The check is in two halves, because a test that reads a shipped text puts that text in its
# job's filter - a declared read applies to every compiled source file of a run - and an edit of
# a guide page or a changelog fragment would then start the whole daemon Go lane. The product
# half scans the files of packages/daemon that name the contract and this one beside them, and
# holds every number it finds to waitingLineContract; packages/daemon/internal/textcheck's
# TestTheWaitingLineContractExtractIsEveryWindowOfTheShippedTexts recomputes these windows from
# the seven files themselves and fails when a text and this copy have drifted apart, printing
# what it computed. Neither half alone is the guarantee: together they are the one the single
# test used to give.
#
# So this file changes in the same commit as the passage it quotes. A window here that no file
# yields, or a renumbered sentence whose window here is still the old one, fails the text-check
# half; a number here that is not the daemon's own fails the product half.
#
# The format: a line `# <path>` opens one window of that file, and every line under it, to the
# next such line, is that window's own bytes. A file the rule yields no window for has no
# section, and docs/site/src/content/docs/legion/troubleshooting.md is that file today - it
# names the field, and the word contract only of a plugin speaking another one, never a number
# beside the field. A window it ever gains is one this file must gain with it.
