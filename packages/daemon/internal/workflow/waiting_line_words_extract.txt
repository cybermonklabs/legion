# What the shipped texts outside packages/daemon say about the waiting line, quoted verbatim:
# the notice a root waiting for a slot gets (workflow.WaitingForSlotNoticeKind) with the name its
# place carries on the wire (api.WaitingLineField), and the fragment that states where the line
# puts an issue whose work came back (record.WaitingLineBand).
#
# The check is in two halves, because a test that reads a shipped text puts that text in its
# job's filter - a declared read applies to every compiled source file of a run - and an edit of
# AGENTS.md or a skill page would then start the whole daemon Go lane. The product half is
# packages/daemon/internal/workflow's TestTheShippedWordsNameTheWaitingLineNotice, which reads
# the files of packages/daemon itself and these sections beside them, and holds each to the
# constant its list is about, so a renamed constant fails there whatever these texts say;
# packages/daemon/internal/textcheck's TestTheWaitingLineWordsExtractIsWhatTheShippedTextsSay
# holds every section here to the file it was taken from, and carries the ban that no excerpt
# can prove - that no file of either list claims a position in the line.
#
# So this file changes in the same commit as the text it quotes: a sentence reworded there and
# not here fails the text-check half, and a constant renamed in the daemon fails the product
# half, which is the one that matters for the words themselves.
#
# The format: a line `# <path> <list> <form>` opens one quotation. `<list>` is `naming`, the
# files that name the notice and the field, or `band`, the files that state the placement, as
# the product test's two lists are named; `<form>` is `raw`, the file's own bytes, or
# `collapsed`, its prose put on one line the way that test reads a wrapped fragment (every
# line's leading whitespace and one `//`, `*` or `#` marker dropped, the words joined by single
# spaces). Every line to the next such line is the quotation's own bytes in that form. A file
# may open more than one section: the two names are a paragraph apart in some of these texts,
# and each section stands on its own in the file it came from.
