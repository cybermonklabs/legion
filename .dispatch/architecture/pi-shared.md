The private workspace package both Oh My Pi plugins bundle (`@legion/pi-shared`): the versioned in-process interface the Envoy plugin publishes and the Legion plugin reads, and the modules both entries inline — the role-claim bridge, the injected-user-turn record, the subagent check, the host types, the jj session attribution overlay every harness's pane commits through — with the real-binary test harness and the shared skills-guard and cross-import rules.

The real-binary harness's `spawnRpc` (`test/omp-harness.ts`) takes `skills`, which leaves `--no-skills` off its flags (`ompFlags`), so the session loads the skills its extensions give and a request carries the skill list a case reads.
That is how a plugin's test sees an experiment arm's folder of texts reach a session: pi-envoy's `dispatch-first-omp.test.ts` names a texts root as the first extension and in `LEGION_TEXTS_ROOT`, and reads from the request that the root's copy of `dispatch-first` is the one with the plain name and that no alias of it is offered.
