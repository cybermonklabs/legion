The Delivery page's record of pull requests, workflow runs and deploys, kept from GitHub two ways. The intakes consume GitHub notifications from NATS on durable consumers (one binder per durable, the other process standing by): `Intake` checks each message's subject before decoding anything, and runs pull requests and workflow runs at once up to the consumer's `MaxAckPending`, in delivery order per pull request or run; `StopDelivering` hands its queued messages back to NATS for the next holder. `Intake` also hands each push of a branch to the architecture importer, while delivery settings are saved (it runs only then) and as no delivery fact, so a component source is imported when its branch moves; it reaches the importer through `PushImports`, an interface this package declares, so the package imports no `architecture` package (`cmd/dispatch` passes the importer to `StartIntakes`). Both intakes route by one `SettingsCache`, read at start and again when `delivery_settings_changed` notifies `dispatch_delivery_settings` (migration 0156). The reconcile (`Reconcile.Run`) is a five-minute timer loop (`duty.RunJittered`, lease `delivery-reconcile`) that catches up what no webhook delivered, since GitHub has no feed of what was missed; `measures` computes the DORA and pipeline figures from the stored rows. It reaches NATS through the listener's bus client (`envoy-listener`), GitHub through the App client (`dispatch-auth`), and decodes envelopes with the generated Go contracts (`contracts`).

The views in `model.go` are what the Delivery page's reads answer: `GET /api/v1/delivery/timeline` and `GET /api/v2/delivery/timeline`, one row of the INFRA-979 tree that keeps its v1 shape in both versions (`OfINFRA979`, `api/routes_versions.go`), and one run with its jobs at `GET /api/v1/delivery/runs/{id}` and `GET /api/v2/deploy-runs/{id}` (`api/route_api_v2_deploy-runs_{id}+get.go`). The first `legion-envoy` release that carries pull request #4274 serves the `/api/v2` paths; the `/api/v1` paths are deprecated from that release and answer the same until a deployment ends `/api/v1`.
